# NFA to DFA Converter

A Java implementation of **Nondeterministic Finite Automaton (NFA) to Deterministic Finite Automaton (DFA)** conversion.

## 📖 About The Project

This project demonstrates the process of converting an NFA into an equivalent DFA using Java. It is designed to explore fundamental concepts of Automata Theory and understand how finite automata can be represented and processed programmatically.

## ✨ Key Concepts

- **NFA:** A finite automaton that can have multiple possible transitions for a given state and input symbol.
- **DFA:** A finite automaton with exactly one transition for each state and input symbol in its alphabet.
- **NFA-to-DFA Conversion:** Constructing an equivalent DFA that recognizes the same language as the original NFA.

## ⚙️ Getting Started

### Prerequisites

- Java Development Kit (JDK)
- A Java IDE, such as IntelliJ IDEA, Eclipse, or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ariyan-bostan/NFA-To-DFA.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NFA-To-DFA
   ```

3. Open the project in your preferred Java IDE.

### Running the Project

Open `Main.java` in your Java IDE and run the program after configuring the JDK.
